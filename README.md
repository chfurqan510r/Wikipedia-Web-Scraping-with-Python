# Wikipedia Web Scraping with Python

## 📌 Project Overview

This project demonstrates how to scrape company data from Wikipedia using Python. The scraped table is converted into a Pandas DataFrame and exported as a CSV file.

## 🛠 Technologies Used

- Python
- Requests
- BeautifulSoup (bs4)
- Pandas

## 📂 Project Files

- web_scraping.py - Python script for web scraping
- companies_data.csv - Scraped data exported as CSV
- requirements.txt - Required Python libraries

## 🚀 Features

- Fetches data from a real website
- Extracts HTML tables
- Cleans the data
- Stores data in a Pandas DataFrame
- Exports the data to CSV

## ▶️ How to Run

1. Install the required libraries

```bash
pip install -r requirements.txt
```

2. Run the Python script

```bash
python web_scraping.py
```

## 📊 Output

The project generates:

- companies_data.csv
